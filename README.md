## 📌 Overview
ENROLLIX is a full‑stack academic enrollment management system designed to replicate real‑world university operations. It integrates a **SQL Server database**, a **Node.js backend**, and a **React frontend** to provide seamless course enrollment, student dashboards, and instructor reporting.

---

## 🔑 Features
- **Database Engineering**
  - Normalized schema with 15+ tables  
  - 12 analytical views for GPA, workload, and section fill rates  
  - Stored procedures, triggers, and transaction handling  

- **Backend Development**
  - RESTful APIs built with Node.js & Express  
  - Modules for prerequisites, waiting lists, swap requests, and fee validation  
  - Error handling with rollback mechanisms  

- **Frontend Integration**
  - React dashboards for students and instructors  
  - Real‑time enrollment updates and reporting  
  - Teacher rating and feedback modules  

- **System Automation**
  - Master reset scripts for batch operations  
  - Audit logging for transparency and reliability  

---

## 🛠️ Tech Stack
- **Database**: SQL Server (SSMS)  
- **Backend**: Node.js, Express.js  
- **Frontend**: React.js  
- **Version Control**: GitHub
